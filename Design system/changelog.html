Changelog

Design system updates, token changes, and component revisions
2026-04-13
Token System
  • Added Type scale — 52 new variables in tokens.css covering all 13 named styles: display, heading, body, label, and caption. Each style exposes -size, -weight, -lh, and -ls (where non-zero).
  • Changed Component heights aligned to 8pt spacing grid — Button MD 44px → var(--space-48), Button SM 36px → var(--space-40), Text Field MD 44px → var(--space-48), Text Field SM 36px → var(--space-40).
Text Field
  • Added Display state — flat list-row with pencil icon, representing the pre-edit / view mode. Added as the 7th state in both the States section and Size × State Matrix. Renamed from "idle" to "Display" to match Carbon / Atlassian / Salesforce conventions.
  • Changed Font sizes tokenized — .tf-label, .tf-input (all 3 sizes), and .tf-display-value (all 3 sizes) now reference type scale tokens instead of hardcoded px values.
  • Fixed LG input height was hardcoded — 56px → var(--space-56).
  • Fixed Display body gap had no token — 2px → var(--space-4).
Button
  • Changed Font sizes tokenized — MD snapped from off-spec 14px to var(--type-label-lg-size) (15px, matching label/large which explicitly targets button text). SM and LG also tokenized.
